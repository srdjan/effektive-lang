## Root-cause notes

The refactor removed the main causes of slices D and G: linear arithmetic, the project loop, the log schema, the stale-output rule, and the disk program now each have one owner. What is left is small.

One cause explains the largest new item. `hostImportSpans` (`emit/spans.ts`) is a project-wide function that only tests call, while `TypeScriptOutputs.spanTable` has no `Project` and so re-derives the same map from one `ModuleInfo`. A per-module function in `spans.ts` that both use would put the rule in one place and make the tested code the production code.

The other worth-fix items are one-line corrections: the stale comment at `check_project.ts:609`, the `shortName` re-derivation at `lower.ts:1535`, and the layering import at `playground/build.ts:18`.

The remaining performance question (G.N7) needs a measurement of `references` on a large file before any code change.
