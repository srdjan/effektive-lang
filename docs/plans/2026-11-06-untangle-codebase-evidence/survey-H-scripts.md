## Root-cause notes
Ten copies of the subprocess helper, nine temp-dir patterns, seven ROOT spellings, and two git-archive copies share one cause: `scripts/` has no shared module, so each script copies a 15-line helper and adjusts it. One `scripts/lib/` (or `scripts/support.ts`) with `ROOT`, `runCommand(cmd, args, opts) -> Result`, `withTempDir`, `writeJson`, and `exportRevision` would put those together and remove about 20 copies. The fast-suite and slow-suite command lines in `deno.json`, `coverage.ts`, `rules_unfired.ts`, and `mutate.ts` would join there as `fastSuiteArgs()`, or be called through `deno task test` with the coverage flags added.

The bench harness has the same cause in a second form: the A/B alternation, row/result/format layout, and `fail`/`succeed` Result builders are repeated per measurement (M1, M3, M4, M7, M2, M5). One `bench/pairs.ts` with `alternate(a, b, step, warmups, steps)` would keep the swap rule and the noise-floor method in one place; `m7.runPairs` is already the right shape and `m1`/`m7:245` both have the same loop inline.

The private-import cluster (`source.ts` for `Result`, `lex.ts`, `check_project.ts`, `lower.ts`, `db.ts`) has one cause: authors of bench files copied the first working import path. Switching to `src/core/mod.ts` or `frontend.ts` for names that are already public removes about 15 edges to private modules. `bench/m2.ts` and `bench/refinement_limits.ts` and `scripts/validate_fixtures.ts` need a decision: add a small "stage timing" export, or accept the reach-in and say so in `docs/architecture.md`.

Version pins have no single table: `TYPESCRIPT_VERSION` in `bench/m5_variants.ts`, `effect@4.1.2` in `bench/ref_update.ts`, `bench/m5.ts` prose. `tests/versions_test.ts` already has the PINS table; adding these rows keeps them current without new structure.

Scripts depending on `tests/helpers.ts` (fixture generators) is intended, since the tests and generators must agree; the missing piece is a name for the pair (e.g. a header comment in the helper listing which task regenerates which fixture).
